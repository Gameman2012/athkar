# نور — athkar

موقع إسلامي يجمع الأذكار والأدعية والقرآن والأحاديث، بواجهة عربية (RTL) بسيطة وأنيقة.

## البنية

```
.
├── src/
│   ├── index.html      ← الصفحة الرئيسية (شبكة الكروت)
│   └── adhkar.html     ← صفحة الأذكار والأدعية (تجلب البيانات من GitHub)
├── data/
│   └── adhkar.json     ← بيانات الأذكار (مصدر واحد لكل الأقسام)
├── README.md
└── AGENTS.md
```

## كيف يعمل

- الصفحة الرئيسية (`src/index.html`) تعرض كروت للأقسام: أذكار وأدعية، قرآن، ذكر مباشر، ورد اليوم، أحاديث.
- صفحة الأذكار (`src/adhkar.html`) تجيب بياناتها عبر `fetch` من رابط **GitHub raw** وليس من ملف محلي، لذلك تعمل مباشرة عند فتحها أو نشرها على GitHub Pages.
- البيانات في `data/adhkar.json`: مصفوفة `adhkar`، كل عنصر فيه `id`، `text`، `count`، `source`، `footer`، و`tags`.

## النشر

تُنشر عبر **GitHub Pages** من الريبو:
`https://github.com/Gameman2012/athkar`

رابط البيانات الخام:
```
https://raw.githubusercontent.com/Gameman2012/athkar/main/data/adhkar.json
```

## إضافة/تعديل أذكار

1. عدّل `data/adhkar.json` (اتبع نفس بنية العناصر الموجودة).
2. تأكد أن الـ JSON سليم (لا فواصل زائدة، أقواس مغلقة).
3. `git add -A && git commit -m "..." && git push`
4. تتحديث الصفحة تلقائياً بعد نشر GitHub (قد يحتاج تحديث المتصفح لتجاوز الكاش).
