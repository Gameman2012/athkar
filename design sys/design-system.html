ملاحظات وتنبيهات

مشاكل في التنسيق بين الصفحات يجب إصلاحها

⚠️ متغيرات CSS مفقودة في بعض الصفحات
الصفحات التالية لا تحتوي جميع المتغيرات:
  • misbaha.html — لا يوجد: --bg-card-hover, --green, --green-light
  • wird.html — لا يوجد: --bg-card-hover, --green, --green-light
  • salah.html — لا يوجد: --bg-card-hover, --green, --green-light
  • tafsir.html — لا يوجد: --green-light
⚠️ اختلاف Container Width
كل صفحة تستخدم max-width مختلف:
  • index.html — 960px
  • adhkar, ahadith, dhikr, quran — 800px
  • tafsir — 700px
  • salah, misbaha — 600px
  • wird — بدون container (flex center)
⚠️ اختلاف Spinner Animation
معظم الصفحات: 0.8s — wird.html: 1s
⚠️ CSS Reset مختلف في wird.html
يستخدم * بدلاً من *, *::before, *::after
💡 التوصية
يجب إنشاء ملف style.css واحد يحتوي جميع المتغيرات والكلاسات الأساسية — ثم كل صفحة تربطه عبر <link rel="stylesheet" href="style.css">
